# BuzzAlvin Music App 🎵

A work-in-progress music streaming web app that streams trending tracks from **Audius API**, developed under the **Buzzalvin** brand by **Olokungbemi Eniola**. 

---

## Current Features

- 🎶 Stream trending songs from Audius
- ⏯ Play / Pause / Next / Previous controls
- 🔄 Shuffle & Repeat
- 🎛 Real-time progress bar and timers
- ❤️ React buttons: love, save, share
- 📱 Fully responsive design for mobile
- 🖼 Display track artwork, title, and artist

---

## 🛠 Tech Stack
HTML • JavaCript • CSS • Audius API

---

## 📌 How to Run
1. Clone the repo:
`git clone https://github.com/BuzzAlvin/buzzalvin-music-app.git`

2. Open `index.html` in your browser
3. Test playback functionality
